# smart-open

> Smart window opener: focuses and moves an existing window to current workspace, or launches fresh.

- Open or focus application by window class regex:
  `smart-open.sh "{{class_regex}}" {{command}} [{{args...}}]`

- Focus existing Kitty terminal or start new:
  `smart-open.sh "kitty" kitty`

- Focus existing Thunar window or start new:
  `smart-open.sh "thunar" thunar`
