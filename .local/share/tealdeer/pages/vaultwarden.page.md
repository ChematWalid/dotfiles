# vaultwarden

> Self-hosted lightweight Bitwarden-compatible password manager running in Docker.
> Accessible locally at https://localhost:8222 or across LAN.

- Open self-hosted Vaultwarden Web Vault in browser:
  `vw`

- Check running Vaultwarden container status:
  `docker ps --filter "name=vaultwarden"`

- Start the Vaultwarden container manually:
  `vaultwarden`

- Launch Rofi credential auto-typer in any window:
  `<Win + P> or <Alt + P>`
