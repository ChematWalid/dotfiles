# jless

> Command-line interactive pager and explorer for JSON data written in Rust.

- Open and explore a JSON file:
  `jless <file.json>`

- Pipe command output into jless:
  `curl -s <url> | jless`

- Expand or collapse JSON nodes:
  Press `Space` or `Enter`

- Search within JSON:
  Press `/` to search values or keys
