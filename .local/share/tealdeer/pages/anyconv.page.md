# anyconv

> Alias to conv: universal smart CLI file converter for media, documents, and data.
> More information: <https://github.com/ACEECA1/anyconv>.

- Convert audio/video using shorthand target extension:
  `anyconv {{path/to/file.flac}} {{mp3}}`

- Batch convert all images in folder:
  `anyconv '{{*.png}}' {{jpg}}`

- List all supported formats and engines:
  `anyconv --list`
