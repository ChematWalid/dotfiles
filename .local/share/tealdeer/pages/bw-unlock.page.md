# bw-unlock

> Unlocks Bitwarden/Vaultwarden vault and saves session token across all terminal tabs.

- Unlock vault and persist session across all current and future terminal tabs:
  `bw-unlock`

- Point Bitwarden CLI to self-hosted local Vaultwarden server:
  `bw-local`

- List all saved vault items:
  `bw list items`

- Get password for a specific item:
  `bw get password {{item_name}}`

- Generate a secure 24-character random password:
  `genpass`

- Generate a secure 4-word hyphenated passphrase:
  `genphrase`
