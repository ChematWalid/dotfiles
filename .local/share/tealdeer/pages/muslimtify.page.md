# muslimtify

> Prayer notification daemon and daily Islamic prayer times CLI for Linux.
> More information: <https://github.com/ChematWalid/muslimtify>.

- Run the background prayer notification daemon:
  `muslimtify daemon run`

- Display prayer schedule for today:
  `muslimtify today`

- Configure calculation method, coordinates, and adhan settings:
  `muslimtify config`

- Check systemd user service status:
  `systemctl --user status muslimtify.service`
