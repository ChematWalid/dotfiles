# serpl

> Interactive TUI for search and replace across projects with live diff preview.
> More information: <https://github.com/yassinebridi/serpl>.

- Start interactive search and replace in current directory:
  `serpl`

- Prepopulate search term:
  `serpl "{{search_pattern}}"`

- Prepopulate search and replace terms:
  `serpl "{{search_pattern}}" "{{replacement_text}}"`
