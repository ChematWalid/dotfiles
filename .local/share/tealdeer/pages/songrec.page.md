# songrec

> An open-source Shazam client for Linux written in Rust.
> More information: <https://github.com/marin-m/SongRec>.

- Recognize a track from the default audio input or monitor:
  `songrec listen`

- Recognize a song from an audio file:
  `songrec audio-file-to-recognized-song {{path/to/file.mp3}}`

- Open the SongRec graphical user interface:
  `songrec-gui`

- Generate Shazam fingerprint from an audio file:
  `songrec audio-file-to-fingerprint {{path/to/file.mp3}}`
