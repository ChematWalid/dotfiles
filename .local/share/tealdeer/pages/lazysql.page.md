# lazysql

> Cross-platform keyboard-driven TUI database manager written in Go.
> Supports PostgreSQL, MySQL, MariaDB, and SQLite with Lazygit-style controls.
> More information: <https://github.com/jorgerojas26/lazysql>.

- Launch interactive database explorer:
  `lazysql`

- Connect directly using a database connection URL:
  `lazysql --url "{{postgres://user:password@localhost:5432/dbname}}"`
