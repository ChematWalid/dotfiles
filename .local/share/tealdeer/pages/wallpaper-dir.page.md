# wallpaper-dir

> View or change the active wallpaper directory with 3-level recursive image discovery.

- Show current wallpaper directory and total image count:
  `wallpaper-dir`

- Set a new wallpaper directory and apply a random wallpaper immediately:
  `wallpaper-dir {{path/to/folder}}`

- Reset wallpaper directory to default Catppuccin Mocha collection:
  `wallpaper-dir reset`
