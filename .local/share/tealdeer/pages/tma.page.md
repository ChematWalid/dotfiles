# tma

> Smart Tmux session launcher with Catppuccin Mocha theme, vim navigation, and TrueColor.

- Attach to running main session or create a new session if none exists:
  `tma`

- List all active tmux sessions:
  `tml`

- Kill a specific tmux session:
  `tmk {{session_name}}`

- Split pane vertically:
  `<Ctrl + a> |`

- Split pane horizontally:
  `<Ctrl + a> -`

- Zoom or unzoom active pane to fullscreen:
  `<Ctrl + a> z`

- Create new window tab:
  `<Ctrl + a> c`

- Detach session (leaves processes running in background):
  `<Ctrl + a> d`
